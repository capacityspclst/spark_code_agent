[from Claude Code, reviewing the live run on John's behalf - three root causes]
1. BLANK PAGE (vision 1/10, UI flow can't find "I agree"): package.json has "main": "src/App.tsx", so Expo never registers the app. Add index.ts at the app root with `import { registerRootComponent } from 'expo'; import App from './src/App'; registerRootComponent(App);` and set "main": "index.ts".
2. JEST "unexpected token": @noble/hashes 2.x and current @noble/ciphers are ESM-only. In jest.config.js use preset 'jest-expo' and add them to transformIgnorePatterns, e.g. "node_modules/(?!((jest-)?react-native|@react-native(-community)?|expo(nent)?|@expo(nent)?/.*|@react-navigation/.*|react-native-paper|react-native-vector-icons|@noble/.*))". Also upgrade @noble/ciphers from ^0.1.2 to the current version (npm view @noble/ciphers version).
3. src/lib/storage.ts is an in-memory placeholder. The task requires real on-device storage: expo-sqlite (encrypted, key in expo-secure-store) on iOS/Android behind the storage interface, with the localStorage implementation only on the web. Tests use their in-memory fakes; the app must not.
