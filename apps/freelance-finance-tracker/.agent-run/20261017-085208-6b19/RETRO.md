   - Expected effect: The hash implementation error is caught early, before the full acceptance suite runs, so the coder can correct the canonicalJson logic in the first or second round, eliminating the cascade of M8 failures.
3. **[medium] Require explicit data schemas and format examples in planner/designer prompts**
